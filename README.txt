CAMPUS CONNECT - FRONTEND STARTER
=================================

Included:
- information.html     Information section
- ask-seniors.html     Ask Seniors listing page
- projects.html        Projects showcase
- style.css            Shared design system and responsive styling
- app.js               Mobile navigation and sample filters

DESIGN DIRECTION
The pages follow the supplied reference video:
- Dark navy top navigation
- Light cool-grey page background
- White rounded content cards
- Cobalt-blue primary buttons
- Clean DM Sans typography
- Restrained spacing, subtle borders and shadows
- Responsive layouts for mobile and desktop

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Keep all five files in the same folder.
4. Open information.html, ask-seniors.html or projects.html with Live Server.
5. Click the navigation links to move between the pages.

IMPORTANT INTEGRATION NOTES
1. These are frontend starter pages with sample content. They do not include a database or real authentication.
2. Replace the sample question cards with your team's backend/database output.
3. Connect the "Log in", "Join the community", "Ask a question" and "Share your project" links to your actual login, registration and submission routes.
4. If your team already has a shared navbar, footer or CSS file, merge these styles rather than creating duplicate versions.
5. If the existing project uses Django, Flask, Java or another backend, your team should adapt the href paths and template syntax to its routing structure.
6. Do not overwrite your existing dashboard or backend files. Copy these pages into a backup/new branch first and integrate carefully.
